# Industry Skills Taxonomy - Curated Skills and Synonyms Reference
## Overview
This document provides a structured taxonomy of skills organized by industry and function. It is used by the CV analyzer/optimizer to normalize skill names, resolve synonyms and acronyms, and match resume skills against job description requirements accurately.

## 1. Taxonomy Structure
### Skill Entry Format
Each skill entry contains:
- **Canonical Name**: The standardized, display-ready name
- **Aliases / Synonyms**: Alternative names, acronyms, or variants that map to this skill
- **Category**: Skill type (Technical, Domain, Tool, Certification, Soft Skill)
- **Industry Relevance**: Which industries most commonly require this skill
- **Seniority Context**: Junior / Mid / Senior / All

### Soft Skill Handling Rules
- Soft skills listed without evidence score 50% less than those demonstrated in bullets
- "Excellent communication skills" in skills section: -2 points vs. "Presented quarterly results to 200+ stakeholders" in experience
- Never penalize for soft skill presence, only for soft-skill-only sections

## 8. Synonym Resolution Rules
### Matching Priority
1. **Exact match** (case-insensitive): Full credit
2. **Alias match**: Full credit (e.g., "JS" → JavaScript)
3. **Partial canonical match**: 80% credit (e.g., "Python scripting" → Python)
4. **Abbreviation match from aliases table**: Full credit
5. **No match**: 0 credit; flag as gap

### Common Mismatches to Handle
| What JD Says | What Resume Says | Resolution |
|---|---|---|
| React | ReactJS | Same — full match |
| JavaScript | JS | Same — full match via alias |
| Machine Learning | ML | Same — full match via alias |
| AWS | Amazon Web Services | Same — full match |
| Scrum | Agile/Scrum | Partial — 80% match |
| MS Excel | Spreadsheets | Partial — 60% match |
| Python | Python scripting | Full match (contains canonical) |
| EHR | Electronic Medical Records | Full match via alias |
| PMP | Project Management Professional | Full match via alias |

## 9. Skills Gap Recommendations by Category
### When a Critical Technical Skill is Missing
- Flag as "Critical Gap"
- Suggest specific courses or certifications to gain the skill
- Recommend adding any transferable/adjacent skills already on CV
- Provide example bullet templates to demonstrate the skill if partially known

### When a Tool-Specific Skill is Missing
- Flag as "Tool Gap"
- Note if a similar tool is present that demonstrates transferable ability
- Suggest free trial or course to gain familiarity quickly

### When a Certification is Missing
- Flag as "Certification Gap"
- Provide estimated study time and cost for popular paths
- Suggest adding any in-progress certifications to CV

## 10. Taxonomy Maintenance Notes
### Update Frequency
- Review and update taxonomy quarterly
- Add new tools/frameworks as they gain mainstream adoption (>10% job posting frequency)
- Deprecate tools no longer mentioned in >1% of job postings
- Add aliases as new abbreviations or marketing names emerge

### Sources for Taxonomy Updates
- LinkedIn Top Skills reports (annual)
- Indeed and Glassdoor job posting analysis
- Stack Overflow Developer Survey (technology skills)
- Bureau of Labor Statistics Occupational Outlook
- Direct industry reports (Gartner, Forrester for tech tools)
