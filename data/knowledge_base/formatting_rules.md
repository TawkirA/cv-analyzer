# Formatting Rules - Complete Resume Formatting Standards
## Overview
Comprehensive formatting guidelines to ensure resumes are visually appealing, professionally presented, and ATS-compatible.
## 1. Document Setup
### Page Configuration
**Page Size:**
- **US Standard**: Letter (8.5" × 11")
- **International**: A4 (210mm × 297mm)
- **Never use**: Legal, Tabloid, or custom sizes
**Margins:**
Recommended Margins:
All sides: 0.75" to 1.0"
Minimum acceptable: 0.5"
Maximum: 1.0"
Balanced Options:
Conservative: 1" all sides
Standard: 0.75" all sides
Space-saving: 0.5" top/bottom, 0.75" left/right
**Orientation:**
- Always use Portrait orientation
- Never use Landscape
### File Format Standards
**Preferred Formats:**
1. **.docx (Microsoft Word 2007+)**
   - Best ATS compatibility
   - Editable by recruiters
   - Universal acceptance
   - Preserves basic formatting
2. **.pdf (Portable Document Format)**
   - Preserves exact formatting
   - Professional appearance
   - Must be text-based (not scanned)
   - Good for email submission
**Format Selection Guide:**
Use .docx when:
Applying through ATS
Employer requests Word format
Conservative industry (finance, legal)
Unsure which format to use
Use .pdf when:
Emailing directly to recruiter
Employer accepts PDF
Using custom fonts or design
Want to preserve exact layout
Creative industry
Never use:
.pages (Mac only)
.odt (limited compatibility)
.rtf (loses formatting)
Image formats (.jpg, .png)
.txt (too basic)
## 2. Typography Standards
### Font Selection
**ATS-Safe Professional Fonts:**
**Sans-Serif (Modern, Clean):**
- **Calibri** - Modern default, excellent readability
- **Arial** - Universal, professional, safe choice
- **Helvetica** - Classic, clean, widely available
- **Trebuchet MS** - Friendly, professional
- **Verdana** - Excellent screen readability
- **Lato** - Modern, professional (if embedded in PDF)
- **Open Sans** - Clean, contemporary (if embedded in PDF)
**Serif (Traditional, Formal):**
- **Georgia** - Elegant, readable
- **Times New Roman** - Traditional, formal
- **Garamond** - Classic, sophisticated
- **Cambria** - Modern serif, professional
- **Book Antiqua** - Elegant, readable
**Fonts to AVOID:**
❌ Comic Sans - Unprofessional
❌ Papyrus - Dated, informal
❌ Brush Script - Too decorative
❌ Impact - Too bold, hard to read
❌ Courier - Looks like typewriter
❌ Decorative fonts - Not ATS-friendly
❌ Script fonts - Hard to read, not professional
❌ Novelty fonts - Unprofessional
### Font Sizing
**Standard Size Guidelines:**
Name/Header: 18-24pt (20-22pt ideal)
Section Headers: 12-14pt (13-14pt ideal)
Job Titles: 11-12pt (bold)
Body Text: 10-12pt (11pt ideal)
Dates/Locations: 10-11pt
Minimum Size: 10pt (nothing smaller)
Maximum Size: 24pt (for name only)
**Size Recommendations by Experience Level:**
Entry-Level (fitting content on 1 page):
Name: 18-20pt
Headers: 12pt
Body: 10-11pt
Mid-Level (1-2 pages):
Name: 20-22pt
Headers: 13-14pt
Body: 11pt
Senior/Executive (2 pages):
Name: 22-24pt
Headers: 14pt
Body: 11-12pt
### Font Styling
**Acceptable Styling:**
✓ Bold - For emphasis (headers, job titles, company names)
✓ Italic - For dates, locations, subtle emphasis
✓ Regular - Body text, descriptions
✓ CAPITALS - Section headers only (use sparingly)
✓ Title Case - Headers, job titles, company names
**Styling to AVOID:**
❌ Underline - Looks like hyperlink, outdated
❌ Strikethrough - Inappropriate for resumes
❌ ALL CAPS body text - Hard to read, looks like shouting
❌ Multiple colors - Unprofessional, ATS issues
❌ Text shadows - Not ATS-compatible
❌ Outlines - Unnecessary, not ATS-friendly
❌ WordArt - Extremely unprofessional
❌ Excessive bold - Loses emphasis effect
**Style Hierarchy Example:**
JOHN SMITH (Bold, 22pt)
john.smith@email.com | (555) 123-4567 (Regular, 11pt)
PROFESSIONAL EXPERIENCE (Bold, 14pt, ALL CAPS or Title Case)
Senior Marketing Manager (Bold, 12pt)
ABC Company | San Francisco, CA (Regular, 11pt)
January 2020 - Present (Italic, 10pt)
• Led marketing team of 12 professionals... (Regular, 11pt)

**Single Column Layout (RECOMMENDED):**
Advantages:
✓ Best ATS compatibility
✓ Clear reading order
✓ Easy to scan
✓ Universal compatibility
✓ No parsing errors
Structure:
┌─────────────────────────────┐
│ NAME │
│ Contact Info │
│ │
│ PROFESSIONAL SUMMARY │
│ Summary text here... │
│ │
│ EXPERIENCE │
│ Job 1 details... │
│ Job 2 details... │
│ │
│ EDUCATION │
│ Degree details... │
│ │
│ SKILLS │
│ Skills list... │
└─────────────────────────────┘
**Two-Column Layout (Use with Caution):**
Risks:
⚠ May cause ATS parsing errors
⚠ Reading order confusion
⚠ Information may be missed
⚠ Not all systems support
Only use if:
Submitting PDF directly to human
Creative industry
Portfolio-style resume
Confident about ATS compatibility
Safe Two-Column Approach:
┌────────────┬────────────────┐
│ Contact │ │
│ Skills │ EXPERIENCE │
│ Education │ (Main focus) │
│ (Sidebar) │ │
└────────────┴────────────────┘
Still risky - test thoroughly!
**Three or More Columns:**
❌ NEVER USE
Extremely poor ATS compatibility
Confusing reading order
Information will be lost
Unprofessional for standard resume

### White Space Management
**Importance of White Space:**
- Improves readability
- Reduces visual clutter
- Guides eye through document
- Creates professional appearance
- Prevents overwhelming reader
**White Space Guidelines:**
Between Sections:
1.5 to 2.0 line spacing
Or 12-18pt space after
Between Job Entries:
1.0 to 1.5 line spacing
Or 8-12pt space after
Between Bullets:
Single spacing (1.0)
Or 3-6pt space after
Around Margins:
Consistent on all sides
Minimum 0.5" breathing room
Within Content:
Don't cram text
Allow natural flow
Balance filled and empty space
**White Space Mistakes:**
Too Much White Space:
❌ Large gaps between sections
❌ Excessive line spacing (2.0+ in body)
❌ Half-empty pages
❌ Looks like padding content
Too Little White Space:
❌ Cramped text
❌ No breathing room
❌ Difficult to read
❌ Overwhelming appearance
❌ Looks desperate to fit everything

## 6. Bullet Points and Lists
### Bullet Point Styles
**ATS-Safe Bullet Options:**
Simple Round: •
Most common
Universally recognized
Clean appearance
Hyphen: -
Very ATS-safe
Plain text compatible
Simple and clean
Small Square: ■
Professional
Good contrast
ATS-compatible
En dash: –
Professional
Clean look
ATS-safe
**Bullets to AVOID:**
❌ Fancy symbols: ★ ◆ ► ✓ ✗
❌ Arrows: → ⇒ ➤
❌ Check marks: ✓ ✔
❌ Custom images/icons
❌ Colored bullets
❌ Multiple bullet styles in same document
### Bullet Point Formatting
**Structure:**
Proper Spacing:
• First bullet point
(3-6pt space after)
• Second bullet point
(3-6pt space after)
• Third bullet point
Indentation:
• Bullet should be at left margin or slightly indented (0.25")
TextText wraps and aligns with first line (hanging indent)
This creates clean, professional appearance
Line Length:
• Keep bullets to 1-2 lines maximum
• Break longer accomplishments into multiple bullets
• Aim for concise, impactful statements
**Bullet Point Content Rules:**
Start with Action Verb:
✓ Led team of 15 engineers...
✓ Increased sales revenue by 35%...
✓ Developed marketing strategy...
Not with Articles:
❌ The project involved leading...
❌ A team of 15 was managed...
Parallel Structure:
✓ Managed budget of $2M
✓ Supervised team of 12
✓ Delivered projects on time
Not Mixed:
❌ Managed budget of $2M
❌ Was supervising team of 12
❌ Projects were delivered on time
### List Formatting
**Skills Lists:**
Comma-Separated (Space-Efficient):

Bulleted (Easier to Scan):
Technical Skills:
• Python, Java, JavaScript, C++
• AWS, Azure, Docker, Kubernetes
• React, Node.js, Django, Flask
Categorized (Most Organized):
Programming Languages: Python, Java, JavaScript, C++, SQL
Cloud & DevOps: AWS, Azure, Docker, Kubernetes, Jenkins
Frameworks: React, Node.js, Django, Flask, Spring Boot
**Education Lists:**

## 15. Common Formatting Mistakes
### Critical Errors to Avoid
**1. Inconsistent Formatting**
❌ Wrong:
PROFESSIONAL EXPERIENCE (Bold, 14pt)
Education (Regular, 12pt)
SKILLS (Bold, 16pt)
✓ Correct:
PROFESSIONAL EXPERIENCE (Bold, 14pt)
EDUCATION (Bold, 14pt)
SKILLS (Bold, 14pt)
**2. Mixed Date Formats**
❌ Wrong:
January 2020 - Present
03/2018 - Dec 2019
2015-2017
✓ Correct:
January 2020 - Present
March 2018 - December 2019
June 2015 - May 2017
**3. Inconsistent Bullet Points**
❌ Wrong:
• First bullet point
Second bullet point
■ Third bullet point
✓ Correct:
• First bullet point
• Second bullet point
• Third bullet point
**4. Poor Spacing**
❌ Wrong:
[Too cramped or too spread out]
✓ Correct:
[Balanced white space throughout]
[Consistent spacing between elements]
[Professional appearance]
**5. Unprofessional Fonts**
❌ Wrong:
Comic Sans, Papyrus, Decorative fonts
✓ Correct:
Calibri, Arial, Georgia, Times New Roman
**6. Using Text Boxes**
❌ Wrong:
[Contact info in text box]
[Skills in sidebar text box]
✓ Correct:
[All content in main document flow]
[No text boxes or floating elements]
**7. Complex Tables**
❌ Wrong:
[Work experience in table format]
[Merged cells and nested tables]
✓ Correct:
[Simple linear format]
[Clear structure without tables]
**8. Poor Color Choices**
❌ Wrong:
Bright red headers, yellow highlighting, rainbow colors
✓ Correct:
Black text, navy blue headers (optional), professional appearance
**9. Excessive Styling**
❌ Wrong:
Bold + Italic + Underline + ALL CAPS + Color
✓ Correct:
Selective use of bold for emphasis
Simple, clean styling
**10. Information in Headers/Footers**
❌ Wrong:
[Contact info in header]
[Page numbers in footer with critical info]
✓ Correct:
[All critical information in main document]
[Optional simple page numbers only]
